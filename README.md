# Longbeach Hotel website

React + Vite + Tailwind. Edit `src/data.js` to change rooms, dining text, contact details and photos.

```
npm install
npm run dev      # local preview at http://localhost:5173
npm run build    # production build into /dist
```

Deploy: push to GitHub, import the repo on vercel.com, click Deploy (Vite is detected automatically).
`vercel.json` makes page refreshes work on routes like /rooms.
